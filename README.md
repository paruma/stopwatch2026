# stopwatch2026

作業時間を意識するため、デスクトップへ付箋のように置けるストップウォッチです。

初期サイズは `400×150 px`、最小サイズは `360×135 px` です。

## 操作

- タイトルまたは右上の想定時間をクリックすると編集できます。
- 想定時間には `90`（90分）または `1:30`（1時間30分）の形式で入力できます。
- 経過時間が想定時間以上になると、経過時間を赤く表示します。
- ウィンドウ内でマウスホイールを回すと、透明度が5%ずつ変わります。
- 経過時間または空白部分をドラッグすると移動できます。
- 四辺・四隅をドラッグすると、縦横比を保ったままサイズを変更できます。
- 右クリックメニューの「閉じる」で終了します。
- 右クリックメニューの「最小化」でタスクバーへしまえます。
- 同じEXEを複数起動できます。状態は保存しません。
- 経過時間には桁が揺れない等幅の `Consolas` 太字を使用します。

## ビルド

.NET 8 SDKを導入したWindowsで実行します。

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false
```

発行された単一ファイルの `stopwatch2026.exe` は次の場所にあります。

```text
bin\Release\net8.0-windows\win-x64\publish\stopwatch2026.exe
```

実行するWindowsには、.NET 8 Desktop Runtime（x64）が必要です。
